WHY AGENTS NEED SKILLS

Why do we need
agent skills?

Agents can reason and recall facts. They still need procedural knowledge: the repeatable way a real job gets done.

WITHOUT A SKILL

Prompt every step.

  • repeat the workflow each time
  • leave the agent to guess
  • lose the sequence and checks
  • make consistency expensive
WITH A SKILL

Load the procedure.

  • name the capability
  • describe when it applies
  • follow the steps in order
  • return a bounded output
Skill = procedural knowledge the agent can load when the task matches.
PROGRESSIVE DISCLOSURE

Load the right knowledge
at the right time.

The agent starts with a lightweight index, then pulls in the procedure and resources only when the task needs them.

01 · INDEXMetadataName + description for every skill.
02 · MATCHTriggerThe request matches the description.
03 · LOADInstructionsRead the full SKILL.md body.
04 · RESOURCESupportFetch scripts, references, or assets.
05 · RUN SAFEDeliverExecute, review, and return the result.
Progressive disclosure: index → instructions → resources.

THE TIME LAYER

Schedules:
how it works.

A schedule tells the agent when to wake up. The skill tells it what to do once it wakes.

01 · DEFINEWhen?Choose a time, interval, or event.
02 · WAKEStartThe scheduler triggers the run.
03 · LOADContextBring in the right context and skill.
04 · ACTWorkUse tools within the boundaries.
05 · DELIVERReturnSend the result, or stay quiet.
Schedule = when to wake + what to run + where the result goes.
CHOOSE THE RIGHT TRIGGER

Heartbeat or
automation?

They share a scheduler, but they solve different timing problems.

HEARTBEAT

Ambient attention.

  • system-owned monitor
  • periodic main-session turn
  • surfaces meaningful changes
  • quiet when nothing needs attention
AUTOMATION

Explicit work.

  • your instructions and schedule
  • one-shot, interval, or cron
  • its own delivery target
  • best for reminders and reports
Rule of thumb: exact job → automation. Ambient awareness → heartbeat.
